# V2.0.0 Release Candidate

## 目标

将论文语料转成受反证检索约束的候选研究问题和执行计划。

## 包含

证据矩阵、候选 gap、固定非创新证明标记、challenge queries、反向证据候选、人工确认门、研究计划、透明持久推荐、AgentRun 和 Job 审计、真实 worker 处理器、MCP 工具合同。

## 不允许的主张

本版本没有证明任何研究空白，也没有完成专家准确率评测。规则式候选引擎是透明产品逻辑，不是新基础模型。

## 正式发布门

联网多源回归、引用链扩展、专家评估集、前端 E2E、Docker restart persistence 和 MCP stdio 全部通过。
