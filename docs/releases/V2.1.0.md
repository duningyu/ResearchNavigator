# V2.1.0 — Real-feedback closure

Date: 2026-08-27

## Scope

V2.1 closes the main real-user feedback gaps in ResearchNavigator while keeping the research claim boundary conservative.

### Implemented in source and deterministic backend tests

- selection-first `PaperSet` workflow; comparison/gap generation no longer silently binds to the newest search session;
- discovery/precise query modes, configurable Top10/20/50, fixed 10-per-page UI, persisted `diversity_seed`, ranking-rule/composition audit;
- Top50 composition target of 10 `classic_candidate` + 40 `frontier_candidate`, with explicit shortfalls instead of fabricated papers;
- search-session corpus restore endpoint and persisted server ranking order;
- richer evidence-grade paper analysis with evidence states, warnings and provenance;
- user-owned PDF list/upload/retrieve/delete lifecycle;
- evidence-aware paper comparison against an explicit project/direction snapshot;
- bounded Gap Explanation with evidence/inference separation, Challenge Search and real human-confirmation gate;
- favorites as a selectable comparison/gap corpus;
- responsive desktop Sider + narrow-screen Drawer source implementation;
- user settings, admin safe runtime config, jobs list/cancel, active source test;
- `SourceRequest` call audit with stable IDs, timestamps, per-record raw hashes and an explicitly defined aggregate provenance hash;
- HTTP-first deterministic acceptance scenario;
- `Idempotency-Key` + `X-Scenario-Version` for core replayable writes;
- safe backup creation plus staged admin restore applied before the next application startup;
- package manager alignment to committed `pnpm-lock.yaml`.

## Verification semantics

`PASS` requires a current-run command. `BLOCKED` means the code path exists but an executable/dependency/network/credential/controlled runtime was unavailable. `SKIPPED` means the capability is intentionally outside the authorized/implemented scope.

Live scholarly-source smoke does not assert fixed titles or fixed counts. It records query, time, source state, stable identifiers and provenance hashes.

## Claim boundary

This release does **not** prove that a candidate gap is novel, that the product improves research quality, or that any live source will return identical results later. `classic_candidate` is a ranking label, not a universal scholarly classification. Automated `--confirm-demo-gap` behavior, when explicitly invoked, is labelled `simulated_human_confirmation` and is not expert review.
