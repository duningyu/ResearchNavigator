# V2.2.0 — Evidence platform

ResearchNavigator 2.2.0 closes the implementation gaps left by 2.1.1 through additive, backwards-compatible subsystems.

## Implemented scope

- lawful OA discovery and policy decisions;
- secure remote PDF fetch and existing parser/index reuse;
- persistent OpenAlex rate-limit cooldown and fallback;
- versioned evidence workflows and worker execution;
- deterministic-first, citation-validated optional LLM enrichment with audit persistence;
- historical trusted-abstract backfill with dry-run and strict identity matching;
- provenance-aware author cards and evidence-bounded dataset cards;
- deterministic direction clustering;
- blinded real-expert evaluation infrastructure;
- Docker persistence acceptance tooling;
- corresponding Web UI entry points and source-level frontend contract tests.

## Explicit non-claims

- A candidate OA URL is not automatically lawful to store; unknown rights remain `link_only` or `rejected`.
- A successful fallback source does not make OpenAlex healthy.
- Provider transport or mocked analysis tests do not prove a live LLM endpoint is available.
- Evaluation infrastructure does not prove expert effectiveness. Until real external experts submit ratings, `expert_outcome_validation=awaiting_real_experts`.
- Docker persistence is only PASS after the current checkout executes the cold-start/restart/down-up/restore harness on a Docker-capable host.
